## 🚀 طريقة التشغيل

### 1️⃣ تحضير المفتاح (مهم جداً)

**مفتاح ExchangeRate-API (مجاني):**
1. ادخل على https://www.exchangerate-api.com/
2. اعمل حساب مجاني (Free plan = 1,500 طلب/شهر)
3. انسخ الـ API key من Dashboard
4. حطو في ملف `.env` (هنعمله دلوقتي)

### 2️⃣ تحضير البوت

تأكد إنك عملت بوت على تليجرام:
1. افتح `@BotFather` على تليجرام
2. ابعتله `/newbot`
3. اختار اسم ويوزر للبوت
4. انسخ التوكن وحطو في `.env`

### 3️⃣ التشغيل على جهازك (للتجربة)

**الطريقة الأسهل — بنقرة واحدة:**

| نظامك | الأمر |
|------|------|
| **Windows** | دابل كليك على `run.bat` |
| **Mac/Linux** | افتح Terminal واكتب `./run.sh` |

**الطريقة اليدوية:**

```bash
# 1. استنسخ المشروع أو فك الضغط
cd currency-bot

# 2. ثبّت المكتبات
pip install -r requirements.txt

# 3. شغّل البوت (التوكن متظبوط بالفعل)
python bot.py
```

> ✅ البوت جاهز — **ما تحتاجش تحط أي توكن**، هو متظبوط في الكود.
> ⚠️ شغّل البوت بـ `python bot.py` مش بـ `python -m bot` عشان `job_queue` تشتغل.

### 4️⃣ النشر على Render (مجاني 24/7)

1. ارفع المشروع على GitHub (private repo)
2. ادخل على https://render.com وسجّل
3. اختار **New +** → **Background Worker**
4. وصّل الـ repo
5. في الإعدادات:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
6. في **Environment Variables** ضيف:
   - `BOT_TOKEN` = توكن البوت بتاعك
   - `EXCHANGE_API_KEY` = مفتاح exchangerate-api
7. اضغط **Create Background Worker**

## 🔧 حل المشاكل

### ❌ البوت مش بيرد
- تأكد إن التوكن صحيح من `@BotFather`
- تأكد إن البوت مش متوقف (send `/start` to @BotFather)

### ❌ "مفيش أسعار متاحة"
- تأكد من مفتاح `EXCHANGE_API_KEY` في `.env`
- افتح الرابط ده في المتصفح:
  `https://v6.exchangerate-api.com/v6/YOUR_KEY/latest/USD`
  لو شغال يبقى المفتاح تمام

### ❌ خطأ `python-telegram-bot` job_queue
- تأكد إنك شغّال `python bot.py` مش `python -m`
- تأكد إن الإصدار 20.7 أو أعلى (الـ job_queue مدمج فيه)
